# Ambiente de Desenvolvimento e Execução (Sprint 7)

## 1. Ambiente de Desenvolvimento
O desenvolvimento e a execução dos testes experimentais do projeto foram realizados utilizando a plataforma GitHub Codespaces. Trata-se de um ambiente de desenvolvimento baseado em nuvem, configurado via contêineres e hospedado em infraestrutura virtualizada.

## 2. Versões das Ferramentas Utilizadas
Abaixo estão detalhadas as versões do interpretador Python, do framework web e da biblioteca de visualização de dados utilizadas no desenvolvimenti do projeto e na preparação sa análise experimental. 

- Python: 3.14.2
- Django: 6.1.1
- Matplotlib: 3.11.2

## 3. Sistema Operacional
A instância virtualizada executou o experimento sob a seguinte distribuição e kernel Linux:

- Distribuição: Ubuntu 24.04.5 LTS
- Codinome: Noble Numbat
- Kernel Linux: 6.8.0-1064-azure
- Arquitetura: x86_64

## 4. Características da Máquina de Execução
As especificações de hardware informadas pelo sistema e alocadas para a execução da instância virtual foram:

- Identificação da Instância: codespaces-e991c2
- Processadores Lógicos Alocados: 2 vCPUs
- Modelo do Processador: AMD EPYC 7763 64-Core Processor
- Memória RAM Total: 3,8 GiB (conforme saída do comando free -h)

## 5. Observações Metodológicas sobre a Execução do Experimento
Para fins de reprodutibilidade e rigor científico na análise de desempenho das estratégias de resposta, faz-se necessário destacar que o GitHub Codespaces opera como um ambiente virtualizado em nuvem. 

Portanto, as especificações técnicas registradas neste documento correspondem estritamente aos recursos computacionais alocados e disponibilizados à instância virtual (codespaces-e991c2), e não ao hardware físico completo ou exclusivo do servidor hospedeiro. Variações na carga de trabalho do servidor compartilhado ou na alocação dinâmica da nuvem podem causar pequenas oscilações nas métricas de tempo de execução e desempenho.
